# Instant Yoga Website

A showcase website for Instant Yoga, presenting classes, pricing, schedule, and online booking with a soft, warm design and clear navigation.

## Description

Instant Yoga is a responsive website built to present the studio’s services in a simple and elegant way. It highlights the different types of classes, the weekly schedule, and the booking process through a clean visual identity.

## Features

- Home page with studio presentation.
- Courses and pricing section.
- Weekly schedule page.
- Booking/contact page.
- Soft color palette and card-based layout.
- Fully responsive design.

## Tech Stack

- HTML
- CSS
- Angular
- TypeScript
